# ファイル詳細: 汎用コメント (MP4)

## 仕様

XFilesはファイルに格納された一般的な `comment` メタデータを、他のファイル情報（場所・サイズ・更新日時・解像度など）と同列のプロパティ項目「コメント」として表示する。「投稿者コメント」や特定サイト名では表示しない。Seal由来かどうかは判定しない。

初期対応は MP4/M4V/MOV コンテナの QuickTime/iTunes `©cmt` atom（`moov/udta/meta/ilst/©cmt/data`）である。`©des` は説明（description）であり **コメントとは別項目**なので、コメントとして代用しない。

メタデータなし・破損・非対応フォーマットではコメント項目を省略し、他の詳細情報は通常通り表示する。コメントに含まれる改行・日本語・長文はコピー可能なままにする。ファイル名やネットから推測しない。

## 読み出しと既存動作との整合性

ファイル詳細を開いたときだけ追加情報を読み込む。既存の `VideoMetadataReader` による時間・解像度・ビットレートの取得とキャッシュは変更しない。MP4の `moov` atomは動画ペイロードより前後どちらにも配置されるため、必要なboxのみ位置指定で読み取る。SMBとローカルの両方を対象とし、巨大・壊れたatomは安全に無視する。

## 対応外

- MKV/WebMその他コンテナのタグ
- MP4の一般的な `mdta` key など別の格納形式
- 説明（`©des`）などの異なるメタデータを「コメント」として表示すること
- 投稿元の調査やコメントの再取得

## 受け入れテスト

1. 一般のMP4の `©cmt` を投稿元にかかわらず読み、日本語・改行も維持。
2. `©des` のみあるファイルは「コメント」を表示しない。
3. コメントのない動画・壊れたatomサイズ・非MP4では安全に省略。
4. `moov` が `mdat` 前後のどちらにあっても取得。
5. 「コメント」はファイル詳細の通常プロパティとして表示し、専用の投稿者項目を作らない。
6. SMB/ローカル・実機で長文選択コピーおよび他の詳細項目に回帰がないこと。
