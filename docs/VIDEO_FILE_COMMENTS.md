# 動画ファイル詳細: 投稿者コメント

## 仕様

Sealがダウンロードした動画内に保存する `comment` メタデータを、XFilesの「ファイル詳細」で「投稿者コメント」として表示する。ファイル名やネットから推測しない。コメントが空・取得不能・非対応フォーマットの場合は項目を表示しない。改行・日本語・長文を許可し、選択/コピー可能な詳細ダイアログの既存動作を維持する。

対象の初期実装は MP4/M4V の QuickTime/iTunes `©cmt` metadata（`moov/udta/meta/ilst/©cmt/data`、可能なら`©des`のフォールバック）。動画再生やSMBの既存 `MediaExtractor` ベースの技術情報抽出とは独立して読み、失敗時は通常の詳細表示を維持する。

既存の動画 `VideoMetadataReader` が処理する解像度・時間・ビットレート等のキャッシュを変更しない。追加コメント取得はファイル詳細を開いた時だけ実行する。MP4の `moov` atom はファイル末尾にも配置されるため、先頭から全ファイルを読み込まず atomサイズに従って必要箇所だけランダムアクセスする。巨大/壊れたatomは安全に無視する。

## 対応外

- MKV/WebMその他コンテナのテキストタグ（将来的に別実装が必要）。
- MP4の任意の `mdta` key や暗号化/ストリームファイル。
- 投稿者コメントをネットから再取得する処理。

## 受け入れテスト

1. `©cmt` のUTF-8・改行の表示。
2. `©des` は `©cmt` がない時のみ採用。
3. コメント不在・破損サイズ・非MP4を安全に無視。
4. `moov` が `mdat` の前後どちらでも取得。
5. SMB/ローカルで既存動画詳細の表示を壊さず、失敗しても詳細自体は表示。
