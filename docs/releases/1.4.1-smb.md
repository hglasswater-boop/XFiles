## Player storyboard

- Added a right-edge action beside **Jump to current position** in the in-player storyboard.
- The new action opens a dedicated **vertical storyboard** without changing the compact horizontal player storyboard.
- The vertical view reuses the existing storyboard cache, current-position highlighting, seek behavior, and long-press fine preview instead of duplicating extraction work.
- Added English and Japanese accessibility labels for the new action.

## Compatibility

- Mobile and TV unit-test variants passed for the player storyboard change.
- Minimum supported Android version remains Android 8.0 / API 26.
