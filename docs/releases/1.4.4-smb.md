## XFiles 1.4.4-smb — NAS media copies visible to Android gallery apps

A signed stable update following `v1.4.3-smb`. This release includes the
Android shared-storage media indexing fix from issue #223 / PR #224.

### Android MediaStore publication

- **NAS → local media copies:** after a supported image (including PNG/JPEG),
  video or audio file has finished copying into shared local storage, XFiles
  requests Android's media scanner to register it with MediaStore. Apps such as
  Samsung Gallery can then discover the file without a device restart.
- **Folders and moves:** completed recursive copies and local fast-renamed
  media paths are indexed as applicable.
- **Avoid incomplete/private files:** a failed or partial transfer is not
  intentionally advertised; hidden paths, `.nomedia` folders and private
  `Android/data` / `Android/obb` locations are skipped.
- Media scanning is asynchronous: visibility may take a little time, and a
  Gallery app's own album visibility filters can still affect what it shows.
  Existing files copied before this update are **not retroactively scanned**.

### Distribution and validation

- Signed **Mobile** (`XFiles-1.4.4-smb.apk`) and **Google TV**
  (`XFiles-TV-1.4.4-smb.apk`) APKs are distributed via GitHub Releases.
  The workflow also builds a Mobile AAB artifact.
- The built-in update checker can discover the newer signed stable release;
  users confirm download and installation. The Nightly channel remains removed.
- CI covers Mobile/TV unit tests, release lint, APK builds and Android emulator
  smoke tests. **Physical Samsung Gallery integration and physical upgrade
  testing are outstanding** and should not be described as hardware-verified.
- For all intervening changes since the prior release, refer to the GitHub
  compare link included in the published release notes.
