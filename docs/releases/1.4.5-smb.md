## XFiles 1.4.5-smb — NAS 宅外アクセス用 WireGuard 自動切替

### 新機能

- SMBサーバー設定に公式WireGuardアプリとの連携を追加。接続先ごとにトンネル名を指定でき、従来のSMB設定では無効が初期値です。
- **宅外**：NASへのTCP接続に失敗したときだけ、設定トンネルの起動を要求し、SMBポートへの到達を確認して1回再試行します。SMB認証エラー・転送エラーではVPNを起動しません。
- **宅内**：VPNがアクティブな状態で、VPNを通らない物理Wi-Fi回線のIPサブネットとNASのTCPポートを確認できた場合に限り、設定トンネルへOFF要求を送信して直接SMB接続します。
- 10秒以内の同一トンネルの連続ON/OFF要求を抑制します。OFFに失敗してもLAN上のNAS操作を妨げません。
- SMB接続定義の編集・複製・暗号化設定バックアップにトンネル設定を含めます。既存設定は維持されます。

### 初期設定

1. Androidの公式WireGuardアプリで自宅NASにアクセスできるトンネルを作成し、手動で動作確認してください。
2. WireGuardの設定で **Allow remote control apps** をONにします。
3. XFilesのSMBサーバー設定でWireGuard連携をONにし、トンネル名を正確に入力し、操作権限を許可します。
4. VPNを経由するNASのIP経路・AllowedIPs・DNSを設定してください。インターネット側にSMB TCP/445を直接公開しないでください。

### 判定・制約

- 宅内判定はWi-FiのIP帯だけではなく、Androidの物理Wi-Fi `Network` へソケットをバインドしてNASのTCPポートに到達することを確認します。Wi-Fi側で到達できないときは誤切断防止のため自動OFFしません。
- VPNロックダウン、同一IP帯を使う外出先ネットワーク、NASの別サブネット配置、WireGuard以外のVPN同時利用などでは動作保証しません。同一IP帯かつ同じIP/ポートで異なるSMBサービスが応答する構成には誤検知リスクが残ります。
- OFFはXFilesから設定したSMB接続を使うときの判定です。バックグラウンドで常時監視したり、関係ないトンネルをOFFにしたりしません。
- WireGuardアプリのブロードキャストには状態確認応答がないため、実際にVPNがON/OFFしたことをXFiles側だけでは保証できません。Android実機での切替は別途確認が必要です。

**対応環境：** Android Mobile（Google TVのVPN切替は検証対象外）。
