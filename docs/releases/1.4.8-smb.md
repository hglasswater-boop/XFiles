## XFiles 1.4.8-smb — WireGuard切断されない問題のVPN迂回制限対策

### 変更
- **宅内SMB接続時のWireGuard自動OFFを改修**しました。従来はVPN動作中に物理Wi-Fi回線を指定したTCP到達確認を先に試していましたが、AndroidのVPNが迂回を許可しないと、この確認が必ず失敗し得ます。
- NASが接続中の物理Wi-Fiと同じIPアドレス帯（実際のサブネットマスクで比較）にあり、VPNネットワークが検出された場合、通常のWi-Fi直接接続が不可能なら、**設定されたWireGuardトンネルを一時OFF**してから、Wi-Fi経由のNAS TCPポート接続を短時間確認します。**TCP確認成功後にのみSMB認証**します。
- 接続できないときは、VPN接続が消えたことを検知できれば指定トンネルへUPを再要求し、復旧後にSMBへ接続します。別のVPN接続が生きている場合、WireGuardを勝手にUPし直しません。
- SMB設定編集画面に「VPN/LAN診断（接続は変更しません）」を追加しました。Wi-FiのIP/プレフィックス、NAS IP、同一IPレンジか、VPN検出、Wi-Fi直接TCP、操作権限が確認できます。
- 接続失敗時の自動再試行ループは禁止し、同一トンネルの短時間のON/OFF重複要求を抑制します。

### 初期設定と検証
1. 公式WireGuard Androidアプリで **Allow remote control apps** を有効化します。
2. XFilesのSMBサーバー設定でWireGuard連携をONにし、トンネル名を正しく入力して制御権限を許可します。
3. 先に「VPN/LAN診断」でIP帯とVPNの状態を確認します（診断では切断しません）。
4. WireGuardをONにしたまま宅内Wi-FiでSMBサーバーを選択して、設定したトンネルがOFFになるか確認してください。

### 注意事項
- **VPNが一時的にOFFになるため、通信に数秒の中断が発生する場合があります。** よくある家庭用IPレンジを同じように使う外出先Wi-Fiでも、一時OFFが起こり得ます。同じIPレンジというだけではNASの本人性は証明できません。
- VPNロックダウン・常時接続設定やWireGuardアプリのリモート操作無効化があると、切断／復旧できない場合があります。切断指示が受信されたか・実際に成功したかをXFilesから確定する公開APIはありません。
- 対象は設定したWireGuardトンネルのみです。Wi-Fi変更だけでVPNを自動切断する常時監視機能ではありません。
- Android実機での切断・復旧の完了と所要時間はCIでは検証できないため、実機で確認が必要です。
