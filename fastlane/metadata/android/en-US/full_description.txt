XFiles is an open-source Android file manager built for X-plore-style dual-pane tree browsing, first-class NAS access, video-heavy workflows and a separate Google TV experience.

SMB / NAS
• Browse saved SMB2/SMB3 servers directly in the normal file tree
• Copy and move between local storage and SMB shares, or between SMB locations
• Show storage usage and optional recursive folder sizes for local and SMB locations
• Show image and video thumbnails from remote folders
• Build storyboard timelines for remote videos and refresh per-video thumbnail caches
• Stream videos directly from SMB through the built-in Media3 player
• Seek through large remote videos without downloading the whole file first
• Protect saved SMB passwords with Android Keystore

DUAL-PANE TREE BROWSER
• Two independent panes, side by side on wide screens and swipeable on phones
• Folders expand in place with tree guide lines
• Copy and move operations confirm the destination before starting
• Per-folder sorting, configurable browser density and context-menu order
• Long operations continue with progress, throughput and cancellation

VIDEO & CAST
• Media3 video player with resume, frame stepping, PiP and visual storyboards
• Two-column vertical storyboard plus long-press fine preview
• Mobile-only Chromecast controller for local and SMB media
• Previous/next, seeking, notification controls and robust handoff state
• Google TV edition uses a separate single-pane remote-first UI and intentionally omits the Cast stack

PACKAGE & MEDIA TOOLS
• Install APK, APKS, APKM, XAPK and AAB packages
• Convert AAB packages on-device with the bundled bundletool stack
• Rebuild supported videos into a new MP4 container without re-encoding using remux
• Select and copy file-detail text and metadata with Android's standard text selection

SEARCH & ARCHIVES
• Recursive filename search with wildcard and extension queries
• Browse zip, jar, apk, 7z, tar (.gz/.bz2/.xz) and rar without extracting first
• Parallel ZIP creation and extraction

SETTINGS & UPDATES
• Password-encrypted settings backup using AES-256-GCM
• Back up browser preferences, favorites, file associations and SMB connections
• Signed in-app update checks for mobile and TV
• Mobile settings separate the latest normal build from a side-by-side diagnostic package

PRIVACY
XFiles has no analytics, no advertising, no account system and no telemetry. Network access is used for features explicitly invoked by the user, primarily SMB/NAS, mobile Chromecast and update checks. SMB credentials stay on the device and saved passwords are protected with Android Keystore. Exported settings backups are encrypted before being written.
