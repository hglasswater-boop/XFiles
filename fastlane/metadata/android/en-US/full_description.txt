XFiles is an open-source Android file manager built for people who want X-plore-style dual-pane tree browsing, powerful local file operations, and first-class NAS access in one app.

Two independent panes keep source and destination visible. Folders expand in place as a tree, archives open like folders, and saved SMB2/SMB3 shares appear alongside local storage instead of living in a separate network screen.

SMB / NAS
• Browse saved SMB2/SMB3 servers directly in the normal file tree
• Copy and move between local storage and SMB shares, or between SMB locations
• Show image and video thumbnails from remote folders
• Prefer embedded video cover art when available
• Stream videos directly from SMB through the built-in Media3 player
• Seek through large remote videos without downloading the whole file first
• Protect saved SMB passwords with Android Keystore

DUAL-PANE TREE BROWSER
• Two independent panes, side by side on wide screens and swipeable on phones
• Folders expand in place with tree guide lines
• Copy and move operations confirm the destination before starting
• Per-folder sorting and configurable browser density
• Folder and file counts shown separately with icons

FILE OPERATIONS
• Multi-select, copy, move, rename, delete and new folder
• ZIP creation and archive extraction
• Skip / overwrite / keep-both conflict handling
• Long operations continue in a foreground service with progress and cancellation

ARCHIVES AS FOLDERS
• Browse zip, jar, apk, 7z, tar (.gz/.bz2/.xz) and rar without extracting first
• Parallel ZIP creation for better performance on large jobs

BUILT-IN VIEWERS
• Image, text and hex viewers
• Audio player
• Media3 video player with frame stepping
• Double-tap left/right for -10 / +10 second seeking
• Right-side vertical swipe for media volume

APP MANAGER & INSTALLER
• Browse installed and system apps, components and split APKs
• Install APK, APKS, APKM, XAPK and AAB packages
• Launch, uninstall or copy APK files out of installed apps

ROOT & SHIZUKU
• Optional su access on rooted devices
• Shizuku support for adb-shell level access without root
• Browse locations such as Android/data where platform restrictions permit
• Read-only privileged mode is enabled by default for safer inspection

PRIVACY
XFiles has no analytics, no advertising, no account system and no telemetry. Network access is used for SMB servers explicitly configured by the user. SMB credentials stay on the device and saved passwords are protected with Android Keystore. Portable settings backups, including optional SMB credentials, are password-encrypted before export.
