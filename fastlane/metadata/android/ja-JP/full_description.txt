XFiles は、X-plore のような 2 ペイン・ツリー型の操作感と、ローカルファイル・NAS をひとつの画面で扱えることを重視したオープンソースの Android ファイルマネージャーです。

左右 2 つの独立したペインを持ち、フォルダは画面遷移せずツリー内で展開。ZIP などのアーカイブもフォルダのように開けます。保存した SMB2 / SMB3 サーバーもローカルストレージと同じツリーに表示されるため、NAS だけ別画面で操作する必要がありません。

SMB / NAS
・SMB2 / SMB3 サーバーを通常のファイルツリーから直接参照
・ローカル ↔ SMB、SMB ↔ SMB のコピー / 移動
・NAS 上の画像・動画サムネイル表示
・動画に埋め込みカバーアートがある場合は優先して表示
・NAS 上の動画を端末へ全ダウンロードせず直接ストリーミング再生
・大容量動画でもランダムアクセスを使ってシーク
・保存した SMB パスワードは Android Keystore で保護

2 ペイン・ツリーブラウザ
・左右 2 つの独立したペイン
・フォルダをその場で展開するツリー表示
・コピー / 移動は実行前に移動先を確認
・フォルダごとのソート設定
・サムネイルサイズやファイル名表示などをカスタマイズ
・フォルダ数とファイル数を個別のアイコンで表示

ファイル操作
・複数選択、コピー、移動、名前変更、削除、新規フォルダ
・ZIP 作成、アーカイブ展開
・競合時の Skip / Overwrite / Keep both
・長時間処理はフォアグラウンドサービスで継続し、進捗表示とキャンセルに対応

アーカイブ
・zip / jar / apk / 7z / tar / tar.gz / tar.bz2 / tar.xz / rar をフォルダのように閲覧
・ZIP 作成は複数 CPU コアを利用して並列処理

内蔵ビューアー
・画像、テキスト、Hex ビューアー
・オーディオプレイヤー
・Media3 ベースの動画プレイヤー
・左右ダブルタップで -10 秒 / +10 秒シーク
・右側上下スワイプでメディア音量を変更
・フレーム単位ステップ再生

アプリ管理 / インストール
・インストール済みアプリやコンポーネント、split APK を閲覧
・APK / APKS / APKM / XAPK / AAB をインストール
・アプリ起動、アンインストール、APK の取り出し

Root / Shizuku
・rooted 端末では su に対応
・root なしでも Shizuku を利用した adb shell 権限アクセスに対応
・Android/data など、通常アプリから扱いにくい場所も利用可能な範囲で参照
・privileged path は読み取り専用モードをデフォルトで有効化

プライバシー
広告、アカウント、解析、テレメトリはありません。ネットワーク権限はユーザーが明示的に設定した SMB サーバーへの接続に使用します。SMB 認証情報は端末内に保存し、パスワードは Android Keystore で保護します。設定バックアップに SMB 認証情報を含める場合も、バックアップ全体をパスワードで暗号化してから保存します。
