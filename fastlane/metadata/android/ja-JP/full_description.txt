XFiles は、X-plore のような2ペイン・ツリー型の操作感と、ローカルファイル・NAS・動画をひとつの画面で扱えることを重視したオープンソースの Android ファイルマネージャーです。Google TV 版は別パッケージとしてリモコン操作向けに最適化しています。

SMB / NAS
・SMB2 / SMB3 サーバーを通常のファイルツリーから直接参照
・ローカル ↔ SMB、SMB ↔ SMB のコピー / 移動
・ローカル / SMB のストレージ使用率と、設定で有効化できるフォルダ容量表示
・NAS 上の画像・動画サムネイル表示
・動画ストーリーボードを生成し、動画単位でサムネイルキャッシュを再生成可能
・NAS 上の動画を端末へ全ダウンロードせず直接ストリーミング再生
・大容量動画でもランダムアクセスを使ってシーク
・保存した SMB パスワードは Android Keystore で保護

2ペイン・ツリーブラウザ
・左右2つの独立したペイン
・フォルダをその場で展開するツリー表示
・コピー / 移動は実行前に移動先を確認
・フォルダごとのソート、表示密度、コンテキストメニュー順序をカスタマイズ
・長時間処理は進捗・転送速度・キャンセル付きで継続

動画 / Chromecast
・Media3 動画プレイヤー、レジューム、フレーム単位ステップ再生、PiP、ストーリーボード
・2列の縦型ストーリーボードと長押しの詳細プレビュー
・モバイル版はローカル / SMB 動画を Chromecast へ送信可能
・前 / 次、シーク、通知操作、動画切り替え時の handoff 状態管理
・Google TV 版は1ペイン・リモコン最適化で、Cast スタックは非搭載

パッケージ / メディア補助
・APK / APKS / APKM / XAPK / AAB をインストール
・AAB は同梱した bundletool 系処理で端末上変換
・対応動画を再エンコードせず新しい MP4 コンテナへ remux
・詳細画面のファイル名、場所、サイズ、日時、MIME、動画メタデータを長押し選択してコピー可能

検索 / アーカイブ
・ワイルドカードと拡張子形式に対応した再帰ファイル名検索
・zip / jar / apk / 7z / tar(.gz/.bz2/.xz) / rar をフォルダのように閲覧
・ZIP 作成 / 展開は並列処理に対応

設定 / 更新
・AES-256-GCM によるパスワード暗号化設定バックアップ
・表示設定、お気に入り、関連付け、SMB 接続を移行可能
・モバイル / TV とも署名済みビルドの更新確認に対応
・モバイル設定では通常版の最新と、別パッケージで共存する診断版を分けてインストール可能

プライバシー
広告、アカウント、解析、テレメトリはありません。ネットワーク権限は、ユーザーが明示的に利用する SMB / NAS、モバイル版 Chromecast、更新確認などに使用します。SMB 認証情報は端末内に保存し、パスワードは Android Keystore で保護します。設定バックアップは書き出し前に暗号化します。
