XFiles 是一款开源 Android 文件管理器，重点提供类似 X-plore 的双栏树形浏览、NAS 访问和视频工作流，并提供独立的 Google TV 遥控器界面。

SMB / NAS
• 在普通文件树中直接浏览已保存的 SMB2 / SMB3 服务器
• 支持本地 ↔ SMB、SMB ↔ SMB 复制和移动
• 显示本地与 SMB 存储使用率，并可选择计算文件夹容量
• 显示远程图片和视频缩略图
• 为远程视频生成故事板，并可针对单个视频重新生成缩略图缓存
• 直接从 SMB 流式播放视频，无需完整下载到本机
• 大型远程视频支持随机读取与 seek
• SMB 密码使用 Android Keystore 保护

双栏树形浏览
• 手机端两个独立栏位，宽屏并排、窄屏可滑动切换
• 文件夹在当前位置展开成树
• 复制 / 移动开始前确认目标位置
• 支持按文件夹排序、显示密度和上下文菜单顺序设置
• 长任务显示进度、传输速度，并支持取消

视频 / Chromecast
• Media3 视频播放器，支持续播、逐帧步进、画中画和故事板
• 双列纵向故事板与长按精细预览
• 手机版可把本地 / SMB 媒体投送到 Chromecast
• 支持上一项 / 下一项、seek、通知控制和稳定的媒体切换 handoff
• Google TV 版使用单栏、遥控器优先 UI，不包含 Cast 控制栈

安装包 / 媒体工具
• 安装 APK / APKS / APKM / XAPK / AAB
• AAB 可通过内置 bundletool 相关组件在设备上转换
• 支持在不重新编码的情况下把兼容视频 remux 到新的 MP4 容器
• 文件详情中的名称、路径、大小、时间、MIME 和视频元数据可长按选择复制

搜索 / 归档
• 递归文件名搜索，支持通配符和扩展名形式查询
• 可像文件夹一样浏览 zip / jar / apk / 7z / tar(.gz/.bz2/.xz) / rar
• ZIP 创建与解压支持并行处理

设置 / 更新
• 使用 AES-256-GCM 的密码加密设置备份
• 可迁移浏览设置、收藏、文件关联和 SMB 连接
• 手机版与 TV 版都可检查签名更新
• 手机设置将最新普通版与可并存的诊断版分开安装

隐私
XFiles 没有分析、广告、账号系统或遥测。网络权限仅用于用户主动使用的功能，主要包括 SMB / NAS、手机端 Chromecast 和更新检查。SMB 凭据保存在设备上，密码由 Android Keystore 保护；导出的设置备份在写入前加密。
